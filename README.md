# ETS2 Radio DJ

Личное радио для Euro Truck Simulator 2 / ATS: играет твою музыку из YouTube Music
через встроенное «радио» игры, показывает обложку в OBS и управляется из Game Bar.

![tech](https://img.shields.io/badge/Python-3.10%2B-blue) ![tech](https://img.shields.io/badge/Windows-10%2F11-blue)

## Как это работает

```
YouTube Music ──> сервер (Flask + yt-dlp) ──> ffmpeg ──> /radio.mp3 ──> ETS2 «Custom Radio»
                                              └──> веб-интерфейс / виджет Game Bar / SMTC / Discord / OBS-оверлей
```

Сервер собирает очередь из твоих лайков/истории/подборок, подмешивает рекомендации,
перекодирует поток в MP3 и отдаёт игре как обычную интернет-радиостанцию.

## Возможности

- **Очередь и радио-волна** — рекомендации тянуться автоматически, после скипа радио не молчит
- **Быстрый выбор** — 6 режимов: Мой Вайб, Микс (свежий бленд каждые 10 минут), Волна трека, Новинки, Лайки, История
- **Вход через Google** — OAuth Device Flow без куки (коды на google.com/device)
- **30 интернет-станций** — Радио Рекорд, Русское Радио, Авторадио, Дорожное радио, SomaFM и др., с проверкой живости потоков
- **Виджет Xbox Game Bar** — вкладки Плеер/Очередь/Радио/Поиск, громкость, обложка
- **Текст песни** — синхронизированные строки (LRCLIB), клик по строке = seek
- **OBS-оверлей** — `/overlay` как Browser Source: обложка + трек + прогресс
- **Телеметрия ETS2** — скорость/передача/топливо, пауза радио при паузе в игре (нужен [ets2-telemetry-server](https://github.com/FredrikHub/ets2-telemetry-server))
- **Discord Rich Presence** — трек в статусе Discord
- **Свои плейлисты** — сохранить текущий трек в плейлист одним кликом
- Библиотека (история/избранное), поиск, альбомы, битрейт 128–256k, усиление звука на лету

## Установка (Windows 10/11)

### Авто — одним файлом

1. Скачай `install_radio.exe` (или репозиторий целиком) и запусти
2. Установщик сам: поставит Python (если нет) → зависимости → зарегистрирует виджет Game Bar →
   добавит медиа-кнопки в автозапуск → **пропишет радио в `live_streams.sii` игры** → запустит сервер
3. В игре: **Radio → Custom → YT Automix DJ**

Ручной вариант: `install_radio.bat` (виден каждый шаг).

### Ручная установка

```
py -3 -m pip install -r requirements.txt
py -3 server.py
start_radio.bat   # сервер + SMTC-мост для медиа-кнопок
```

Затем пропиши в `Documents\Euro Truck Simulator 2\live_streams.sii` (внутри `live_streams: (N,`):

```
	.stream_data[]: "http://127.0.0.1:5000/radio.mp3|YT Automix DJ|Custom|RU|128|1",
```

и увеличь счётчик `N` на 1. Либо кнопка **«Прописать»** в настройках веб-интерфейса делает это сама.

### Вход в Google Music (опционально)

Без аккаунта работает поиск, подборки и станции. Лайки/история/плейлисты — после входа:

1. Настройки → Аккаунт → **Google OAuth (без куки)**
2. Один раз создай OAuth-клиент типа **TVs and Limited Input devices** в
   [Google Cloud Console](https://console.cloud.google.com/apis/credentials) и вставь Client ID/Secret —
   сервер запомнит их навсегда
3. Кнопка → Google откроется сам → введи код → готово

> Пока приложение в статусе *Testing*, Google убивает refresh-токен раз в 7 дней —
> просто нажми кнопку входа снова, или опубликуй приложение (**Publish App**) в OAuth consent screen.

## Веб-интерфейс

| Вкладка | Что там |
|---|---|
| Подборки | Быстрый выбор, 12 карточек на страницу |
| Очередь | Полный список с drag-reorder |
| Плейлисты | Плейлисты YouTube Music + свои сохранённые |
| Библиотека | История / Избранное |
| Радио | 30 станций с health-check |
| Поиск | Треки, альбомы, ссылки YouTube |
| Аккаунт | OAuth / Cookie / каналы |
| Настройки | Битрейт, громкость, кеш, Discord, радио в игре |

Горячие клавиши: **Space** — пауза, **←/→** — назад/скип, **L** — лайк, **D** — дизлайк, **Y** — текст песни.

## Проект на диске

```
server.py          — весь сервер (Flask, очередь, рекомендации, станции, OAuth)
static/            — style.css + app.js веб-интерфейса
overlay.html       — OBS-оверлей
RadioWidget/       — исходники виджета Game Bar (C#/UWP)
install_radio.exe  — установщик одним файлом
smtc_bridge.ps1    — медиа-кнопки Windows (Play/Pause/Next в Game Bar и на клавиатуре)
```

Кеш треков по умолчанию **выключен** — всё стримится напрямую, на диск ничего не пишется.
Тумблер «Кеш на диск» в настройках включает локальный кеш для быстрых повторных треков.

## Заметки

- Все личные данные (токены, куки, история) хранятся рядом с `server.py` и в git не попадают
- Российские радиопотоки могут быть недоступны вне РФ (гео-блок CDN) — вкладка «Радио» подсвечивает недоступные
- OBS: добавь `http://127.0.0.1:5000/overlay` как Browser Source; параметры `?compact=1` (без обложки), `?scale=1.5`, `?nobg=1` (прозрачный фон), `?shadow=1` (тень вместо плашки)

## Отказ от ответственности

Проект для **личного использования**. Загрузка контента через yt-dlp может нарушать
условия использования YouTube — используй на свой страх и риск. Никакого контента
в репозитории нет, только плеер.
