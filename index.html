Вход без куки: кнопка → Google откроется сам → вводишь код → готово.

1. Открой console.cloud.google.com → Credentials
2. Create Credentials → OAuth client ID → тип TVs and Limited Input devices
3. Скопируй Client ID + Client Secret в поля: сервер запомнит их навсегда.
